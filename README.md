## Universal Compatibility
This framework supports any browser-based enterprise application:
- React / Angular / Vue SPAs
- Oracle ADF / Oracle Fusion
- SAP Fiori
- Manhattan WMS / SCM
- Salesforce Lightning
- ServiceNow
- Legacy JSP / ASP.NET apps
- iframe-heavy apps
- Shadow DOM apps
- SSO / Azure AD / Okta authenticated apps
- Enterprise grids (ag-Grid, Kendo, PrimeNG)

## Setup

```bash
npm install
npx playwright install
cp .env.example .env   # fill in your credentials
```

## Authenticate (SSO Setup — run once)

```bash
npx playwright test tests/auth.setup.ts --project=setup
# Creates .auth/user.json (gitignored)
```

## Run Tests

```bash
npm test                   # run all tests
npm run test:headed        # headed mode (see the browser)
npm run test:allure        # run + generate Allure report
npm run allure:open        # open Allure report
SKIP_AUTH=true npm test    # skip SSO login (public apps)
```

## Project Structure

```
tests/                → test specs (.spec.ts)
  auth.setup.ts       → SSO / OAuth login setup
pages/                → Page Object Models
  BasePage.ts         → Base class with all helpers pre-loaded
utils/
  iframeHelper.ts     → iframe locator & interaction utilities
  shadowDOMHelper.ts  → shadow DOM traversal
  gridHelper.ts       → enterprise grid / table helpers
  modalHelper.ts      → dialog / modal handling
  ssoLoginHelper.ts   → SSO / Azure AD / Okta abstraction
  retryHelper.ts      → retry strategy for flaky interactions
  envConfig.ts        → centralised env variable loading
.env.example          → required environment variables (copy to .env)
.auth/                → stored auth state (gitignored)
allure-results/       → raw Allure data (gitignored)
allure-report/        → generated HTML report (gitignored)
```

## Security

- All credentials are in `.env` (gitignored — never commit)
- SSO session stored in `.auth/` (gitignored)
- No hardcoded credentials in any source file

## CI

Set `BASE_URL` (and any app credentials) as GitHub Actions secrets/variables.
